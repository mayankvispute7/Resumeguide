ATS Friendly Resume Guide

Create a Professional ATS-Friendly Resume Using Overleaf + ChatGPT

1
Step 1

Open Overleaf

Open the official Overleaf website to get started.

Go to Overleaf
2
Step 2

Create Account

Sign up using Google, GitHub, or Email and login to your account.

3
Step 3

Open Resume Templates

Open the Overleaf Resume Templates page to find professional layouts.

Browse Templates
4
Step 4

Search Harshibar Resume

In the search bar type:

Harshibar Resume
5
Step 5

Open as Template

Click Open as Template so the Overleaf code editor opens.

6
Step 6

Copy Full LaTeX Code

Click inside the code editor on the left side, then press CTRL + A and then CTRL + C to copy the full LaTeX code.

7
Step 7

Open ChatGPT

Open ChatGPT or any AI tool.

Go to ChatGPT
8
Step 8

Upload Your Old Resume PDF

Upload your old resume PDF so AI can extract your information.

9
Step 9

Copy This Prompt

Copy the exact instructions below to tell the AI how to process your template.

Copied 
You are a LaTeX Overleaf resume editor.

I will provide:
1. A LaTeX resume template code
2. My old resume PDF

IMPORTANT:
- The LaTeX template already works properly.
- Do NOT change the design.
- Do NOT change formatting.
- Do NOT change spacing.
- Do NOT change packages.
- Do NOT add new sections.
- Do NOT remove anything from the template structure.
- Do NOT modify LaTeX commands unnecessarily.
- Do NOT rewrite the entire code.
- Do NOT generate a new template.

YOUR ONLY JOB:
- Extract my information from the uploaded PDF resume.
- Replace ONLY the demo/sample person's information in the LaTeX template with my information.
- Keep everything else EXACTLY SAME.

IMPORTANT:
- Keep the same LaTeX structure and syntax.
- Keep all formatting exactly same.
- Ensure the code compiles in Overleaf without errors.

OUTPUT RULES:
- Return ONLY the final complete LaTeX code.
- Start directly from:
\documentclass
- End with:
\end{document}
10
Step 10

Paste the Prompt

Paste the copied prompt into ChatGPT.

11
Step 11

Paste the Overleaf Code

After the prompt, paste the full copied LaTeX code from Overleaf.

12
Step 12

Generate Resume

AI will generate your ATS-friendly personalized LaTeX resume code.

13
Step 13

Copy AI Generated Code

Copy the complete generated code from ChatGPT.

14
Step 14

Paste Back Into Overleaf

Remove the old code and paste the new AI generated code.

15
Step 15

Click Recompile

Click the Recompile button in Overleaf.

Step 16

Download Resume PDF 🎉

Your professional ATS-friendly resume is now ready to download.
